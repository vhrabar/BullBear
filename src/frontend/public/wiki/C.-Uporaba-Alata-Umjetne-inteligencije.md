# Uporaba Alata Umjetne Inteligencije

Ova sekcija navodi sve slučajeve u kojima su upotrijebljeni LLM alati, njihove prednosti, te pojedinosti o načinu korištenja.

## Ispravak pravopisnih i jezičnih pogrešaka u Wiki sekciji

Google Gemini 2.5 Flash upotrijebljen je za ispravak jezičnih i pravopisnih pogrešaka u Wikiju.
Alat je omogućio automatsko prepoznavanje gramatičkih nepravilnosti, te neusklađenosti u stilu pisanja. Korištenjem ovakvog sustava znatno je smanjeno vrijeme potrebno za lekturu, a osigurana je i viša razina jezične preciznosti. Uporaba alata nipošto ne utječe na razvijanje sposobnosti pisanje dokumentacije, već ubrzava postupak lektoriranja kakav pružaju servisi poput ispravi.me

## Automatski PR Code Review

GitHub Copilot konfiguriran je da pruža automatski Code Review unutar svakoga Pull Requesta.
Sustav analizira prijavljene promjene u kodu, predlaže optimizacije, upozorava na potencijalne logičke ili sigurnosne nedostatke, te osigurava usklađenost s postojećim standardima. Ovakav je pristup u zadnje vrijeme postao djelom standarne prakse, te nipošto ne utječe negativno na osnovne ciljeva projekta.
